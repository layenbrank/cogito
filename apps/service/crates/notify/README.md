# notify · 出站通知

面向用户与第三方的出站通知：邮件、短信、webhook。

## 数据所有权

无表。通知失败重试由 `audit` 的 outbox 承载，本 crate 不持久化投递状态。

## 对外接口

- `Notifier` 端口：以「通知意图（收件人、模板、变量）」为契约，调用方不感知渠道。
- 渠道实现（邮件 / 短信 / webhook）由调用方注入，便于测试与替换供应商。
- 模板渲染与发送结果：同步返回投递结果，异步重试交给 outbox 消费方。

## 边界约束

- 不依赖 HTTP 框架；不依赖 `cogito`（R1）。
- 凭据（SMTP、webhook secret）由调用方注入，不落此 crate 的配置。
- 通知内容不得包含密钥或完整个人信息；日志只记录通知 ID 与结果。
- 权限判断调用 `authz`（R3）。

## 迁移状态

- 待迁入（P6）：来源为散落在 `service/src/services/*` 的邮件 / 短信 / webhook 发送逻辑；迁完后删除。
