## 0. 提交路径说明（先读）

Partner Center 有两条路，**不要混**：

| 路径 | 包怎么交 | 你们现状 |
|------|----------|----------|
| **EXE or MSI app**（`win32apps/...`） | 填 **HTTPS 包托管 URL** | ✅ 当前路径 |
| MSIX / 传统应用 | 直接上传 `.msix` | ❌ Tauri v2 不原生出 MSIX |

因此：**必须**自备 CDN/R2/Worker 托管安装包；看不到「上传 MSIX」是正常的。

上架硬性前提（与托管无关）：

1. 安装包为**离线完整** `.exe` / `.msi`（非 stub）
2. **代码签名**证书链到 Microsoft Trusted Root（自签名不行）
3. **静默安装**（NSIS：`/S`）
4. WebView2 使用 **`offlineInstaller`**（Store 要求离线安装包；当前 `tauri.conf.json` 已配置）
5. 包 URL **版本化**，提交后该 URL 上的文件**不得覆盖**

| 声明 | 勾选 | 说明 |

### 3.5 系统要求（可选）

可不填。若填，建议只标「推荐」：

| 硬件 | 建议 |
|------|------|
| 键盘、鼠标 | 推荐 |
| 触摸屏 | 可选推荐 |


当前账号若「未找到域」，可选：

1. 先用 Worker / r2.dev 上架  
2. 购买或添加域名后再换自定义域，并**新提交**新包 URL  

名称示例：`downloads.你的域名.com`（不必再在路径里写一层产品名）。

## 10. 常见问题

**Q：文件名必须是 setup.exe 吗？**  
A：否。只要是 `.exe`/`.msi` 的版本化 HTTPS 直链即可。

**Q：必须买域名吗？**  
A：否。Worker / r2.dev 可用于上架；自定义域仅影响品牌与长期运维。

**Q：为什么绑不下 downloads.i-thinking.com？**  
A：该根域须已在本 Cloudflare 账号用 Cloudflare DNS 托管；账号「域名」为空时无法绑定。

**Q：MSIX 在哪配置？**  
A：当前是 Win32 EXE 路径，无 MSIX 上传项。改走 MSIX 需另建产品类型并自行打包，Tauri 默认不产出 MSIX。

**Q：许可条款和版权信息有何区别？**  
A：版权是一行权属声明；许可条款是完整使用协议（一览必填）。
