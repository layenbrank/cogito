产品概述：
cogito 是 Windows 桌面生产力应用，提供磁贴工作台、导航、日历提醒、本地笔记、截图标注、Morph 文档处理，以及可选的账号/同步与智能对话。

登录（可选）：
大部分功能可在未登录时本地使用。若需测试账号相关功能，请使用：
用户名：cogito
密码：123456

隐藏/次要功能访问：

- 设置：通过应用内设置入口
- Morph 文档处理：通过对应磁贴/功能入口选择本地文件
- 截图标注：由用户主动触发截图
- 智能对话：由用户主动打开对话功能；内容会发往相应服务生成回复

生成式 AI：
本产品包含可选的生成式 AI 对话功能。未使用该功能时，核心本地能力不受影响。

依赖项：
不依赖非 Microsoft 驱动程序或 NT 服务。文档处理与截图等通常在本地完成。

其他：
请确保测试环境可联网，以便验证检查更新、可选登录/同步及智能对话（若测这些场景）。
