# 02 — 竞品与「为什么不好用」

## 1. 对标地图

| 产品 | 定位 | 强项 | 常见不爽 |
|------|------|------|----------|
| **Trello** | 通用看板 | 直观、卡片附件生态 | 拖拽偶发卡顿；权力升级后变乱；云端强绑定 |
| **Notion Board** | 文档库的一种视图 | 与 DB 一体 | 看板是副视图；性能与专注度差；新建路径长 |
| **Linear** | 工程任务 | 键盘、速度、状态清晰 | 团队/Issue 模型重；个人轻量场景过重 |
| **Height / Plane** | 现代项目管理 | 视觉新、视图多 | 功能面宽，个人「只想挪卡片」成本高 |
| **Microsoft Planner** | 微软套件 | 集成 Teams | UI 冗、拖拽反馈弱 |
| **本地笔记看板**（部分 Markdown 插件） | 离线 | 隐私 | 交互原始、无系统级提醒 |

## 2. 痛点 → Signboard 对策

| 痛点 | 对策 |
|------|------|
| 拖拽不稳 / 无落点 | `@dnd-kit` 多容器 + DragOverlay + 2px 落点条；`activationConstraint.distance=6` 防误触 |
| 只能鼠标 | 列内 `⌘↑↓`、跨列 `⌘←→`；文档化快捷键 |
| 卡片字段爆炸 | 卡片面仅：标题 + 到期 chip + ≤2 标签；其余进侧栏 |
| 新建摩擦 | 列底 inline input；全局 `⌘N` 聚焦新建 |
| 到期是摆设 | `reminderID` / `dueAt` 对接现有 Reminder；可选写入 Calendar 块 |
| 看板与「文件夹」混淆 | **不**复用 `magneticTile.collectionID`；独立 `signboard*` 表 |
| 视觉模板感 | Soft UI + 产品主色；shaders 仅空态/微反馈 |
| 云端优先 | MVP 纯本地 SQLite；同步表结构预留 `syncedAt` 可选字段（可空，不实现逻辑） |

## 3. 差异化一句话

> **桌面磁贴上的本地看板：拖拽手感 + 提醒同源，不做第二个项目管理套件。**

## 4. 体验对标（应学 / 应避）

**应学**

- Linear：键盘密度、状态色克制  
- Trello：列底快速添加  
- Apple Reminders：到期与通知一体  

**应避**

- Notion：把看板塞进万能 DB  
- Jira：必填字段与工作流配置墙  
- 过度 Bento / 统计仪表盘抢第一屏
